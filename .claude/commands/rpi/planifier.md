## Entrée utilisateur

```text
$ARGUMENTS
```

## Prérequis

Le fichier `documents/plans/<section-slug>-recherche.md` doit exister avec un statut GO.

## Objectif

Construire un plan de rédaction détaillé et validé avant de produire le texte final.

## Étapes

1. **Lire le rapport de recherche** : `documents/plans/<section-slug>-recherche.md`
2. **Définir la structure** :
   - Titre et position dans le mémoire
   - Nombre de paragraphes estimé
   - Idée centrale de chaque paragraphe
   - Sources à mobiliser par paragraphe
   - Données chiffrées à intégrer
3. **Vérifier la cohérence** avec les sections adjacentes
4. **Valider les hypothèses** : vérifier que le plan répond aux objectifs spécifiques concernés (OS1–OS6)
5. **Présenter le plan à valider** avant rédaction

## Sortie

Plan dans `documents/plans/<section-slug>-plan.md` :
- Structure paragraphe par paragraphe
- Sources mobilisées
- Données nécessaires
- Liens avec les objectifs spécifiques du mémoire
