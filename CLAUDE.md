This file references the AI agents available for this project. Use these agents to get specialized assistance for different aspects of development.

## 📦 Active Agents

### Engineering

- **[Backend Architect](./.claude/agents/engineering/backend-architect.md)** — System design, APIs, databases, and scalability
- **[Frontend Developer](./.claude/agents/engineering/frontend-developer.md)** — UI/UX, components, performance, accessibility

## 🚀 How to Use

Reference these agents in your prompts to get specialized guidance:

```
"Acting as the Backend Architect agent, design a database schema for storing memoir entries with user authentication."

"As the Frontend Developer agent, create a React component for displaying and filtering memoir entries."

"Using the DevOps Automator agent, set up a GitHub Actions workflow to test and deploy this Node.js application."
```
